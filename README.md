# oicon2026

ハッキング風の演出プログラム（ブラウザで動くジョーク演出です。実際のハッキングは一切行いません）。

## 遊び方

1. `index.html` をブラウザで開く（GitHub Pages を有効にしている場合はそのURLを開く）
2. 画面をクリックすると全画面になります
3. パスワード画面で `yes東京` と入力して Enter
4. テレビが消えるような演出のあと、約4秒のハッキング演出が始まり「ACCESS GRANTED」で完了

## カスタマイズ

`index.html` 内の以下を書き換えると調整できます。

- `PASSWORD` … 合言葉
- `HACK_MS` … ハッキング演出の長さ（ミリ秒）
